Template Matching

Load a large target image and a small template. The template is compared with every position of the target, and the best-scoring spot is boxed. The three methods use the same formulas as OpenCV's matchTemplate, computed in plain JavaScript, so this works offline.

Large images are scaled down to 480 px (the template by the same factor) to keep the browser fast. Confidence shows how far the best score stands above the average score over all positions. The threshold only decides MATCH or NO MATCH; it never changes the score.

Haar-like features

Light and dark rectangles. The value is the white sum minus the black sum, for example a dark eye band over brighter cheeks.

Integral image

Each pixel stores the sum of everything above and to its left, so any rectangle sum takes four lookups.

AdaBoost

Picks the most useful features out of thousands and combines weak classifiers into a strong one.

Cascade

Cheap stages first. Most background windows are rejected early, which makes detection fast.

DeepFace

DeepFace (Facebook, 2014) verifies faces with a deep neural network trained on millions of images.

DeepFace concept demonstration

No DeepFace network runs in this page. To show the comparison step, each image is shrunk to 16×16 grayscale, centred and normalised. The numbers are real maths on that simple descriptor, not DeepFace output, and they do not prove identity.

FaceNet

FaceNet (Google, 2015) maps a face to a compact embedding so that distance directly reflects similarity.

FaceNet educational demonstration

No FaceNet model runs here. The metrics use the same 256-value pixel descriptor as the DeepFace demo, not real FaceNet embeddings.

Triplet loss

L = max(‖f(a)−f(p)‖² − ‖f(a)−f(n)‖² + α, 0). Training pulls the positive close and pushes the negative at least a margin α away.

Privacy and responsible use

  • Use only images you have permission to analyse.
  • Avoid sensitive or private photos.
  • Face-matching results are not proof of identity.
  • Do not use this for surveillance, tracking without consent, or high-impact decisions.

Images are processed locally in your browser and are never uploaded. The only network requests are OpenCV.js and the Haar cascade file for the Viola–Jones demo.
